# Super Spy Guard

Super Spy Guard is an iOS app for room safety checks, nearby-device checks, scan history, and PDF reports.

## Support

Need help with Super Spy Guard?

- Support page: https://snarfnet.github.io/SuperSpyGuard/support.html
- Privacy policy: https://snarfnet.github.io/SuperSpyGuard/privacy.html
- Issue tracker: https://github.com/snarfnet/SuperSpyGuard/issues

When you contact support, include the app version, device model, iOS version, and a short description of what happened. Please do not post private scan details publicly.
